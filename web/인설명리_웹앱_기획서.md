# 인설명리 웹앱 기획서

작성일: 2026-10-16 (한국 시간)
기준: Android 앱 **인설명리 1.06** (versionCode 7, 계산 기준 `KR-2026.10-4`)
목적: Google Play 앱과 별도로 **브라우저에서 바로 쓰는 웹앱**을 만들어 사용자 유입과 광고 수익을 늘린다.

이 문서는 새 대화창이나 다른 개발자가 웹앱을 처음부터 만들 수 있도록 정리한 자료입니다. 앱의 기능, 화면, 디자인, **사주팔자와 자미두수 명반을 정하는 계산 규칙**, 수익화 방법, 작업 순서를 담았습니다.

> 계산 결과는 Android 앱과 **완전히 같아야** 합니다. 같은 사람을 앱과 웹에서 봤을 때 결과가 다르면 신뢰를 잃습니다. 7장의 기준 사례로 반드시 대조하세요.

## 2. 현재 앱의 기능 (1.06 기준)

### 2.1 화면 구성

```
하단 탭:  [명반]  [달력]  [보관함]

명반 탭:  입력 화면 → (결과 보기, 이때 전면 광고) → 결과 화면
결과 화면 상단: 편집 · 보관함 · 저장 아이콘, 프로필 카드(이름 · 양력/음력 일시 · 지역 · 일주)
결과 탭:  [사주팔자] [자미두수 명반] [종합 통변]
  사주팔자 하위 탭: [원국] [운 흐름] [통변]
  자미두수 명반 하위 탭: [선천 명반] [대한 명반] [유년 명반]
```

### 2.2 입력 화면

| 항목 | 내용 |
| --- | --- |
| 이름 | 비워 두어도 됨. 안내 문구 "이름 입력 (선택)". 비우면 "이름 없음"으로 표시 |
| 성별 | 여자 / 남자 |
| 달력 | 양력 / 음력 / 음력 윤달 |
| 생년월일 | 날짜 입력 창(년·월·일 숫자 입력). 1900-01-01 ~ 2050-12-31 |
| 출생시간 | 시:분. "출생시간 모름" 체크 가능 |
| 출생 지역 | 도시 선택(기본 서울특별시). 지역 경도 보정은 선택 사항 |
| 서머타임 겹치는 시각 | 1987·1988년처럼 같은 시각이 두 번 있는 경우 앞/뒤 선택 |
| 결과 보기 | 누르면 계산. 계산 중 문구: "사주와 자미두수 명반을 계산하고 있어요. 잠시만 기다려 주세요." |

### 2.3 사주팔자

- **원국**
  - 원국표: 시·일·월·년 4기둥, 왼쪽부터 이 순서. 행은 천간·십신·지지·십신·지장간·12운성.
  - 핵심 요약: 일주, 강약, 용신·희신·기신·구신, 격국, 합충.
  - 오행·십신 비율 차트: [기본] / [합충 반영] 전환.
- **운 흐름**
  - 대운 8칸, 세운, 월운 12칸. 모두 **오른쪽에서 왼쪽으로** 흐릅니다(가장 이른 운이 오른쪽 끝).
  - 대운을 누르면 세운이 그 대운의 10년으로 바뀝니다. 현재 운은 강조 표시합니다.
- **통변**: 6개 탭(총론·성격·적성·연애·재물·건강). 친근한 존댓말입니다(6장).
- **출생시간 모름**
  - 시주 없이 일·월·년주만 보여 주고, 강약·용신·대운은 제공하지 않습니다.
  - 절입일에는 "절입 후 | 절입 전" 두 경우의 월주(입춘이면 년주도)를 한 표에 보여 줍니다.

### 2.4 자미두수 명반

- 12궁 명반(4×4 격자, 가운데 2×2는 명반 정보)과 확대 보기, 궁을 누르면 상세 보기.
- 별 표시: 14주성, 보좌성, 살성, 잡성, 묘왕리함(밝기), 사화 배지(록·권·과·기 색 배지).
- 삼방사정 연결선: 명궁에서 재백·관록으로 금색 선, 천이로 청색 선.
- 선천 / 대한 / 유년 명반 전환. 대한·유년에서는 궁 이름과 사화만 바뀌고 별 위치는 그대로입니다.
- **자미두수 통변**: 6개 탭. 대한·유년 명반에서는 그 시기의 흐름을 풀이합니다.
- 출생시간을 모르면 명반을 만들지 않고 다음 문구를 보여 줍니다: "출생시간을 입력해야 명반을 완성 시킬 수 있습니다."

### 2.5 종합 통변

사주와 자미두수 선천 명반을 함께 본 풀이입니다. 소제목은 **본모습 · 힘이 나는 곳 · 재물 · 채우면 좋은 점** 4개입니다. 출생시간을 모르면 안내 문구를 보여 줍니다.

### 2.6 달력 (만세력)

- 1900~2050년 월 달력입니다. 날짜마다 일진 간지, 한국 음력(윤달 표시), 절기와 절입 시각(한국 시각)을 보여 줍니다.
- 날짜를 누르면 상세 정보가 나옵니다. 보관함의 사람을 선택하면 그 사람 일간 기준 십신을 함께 봅니다.

### 2.7 보관함

- 결과를 이름과 함께 저장합니다(기기 안에만). 검색, 고정, 삭제(되돌리기 가능)를 지원합니다.
- 저장할 때 그때의 계산 결과(스냅샷)와 계산 기준 버전을 함께 보관합니다.
- 다시 열면 저장 당시 결과를 보여 주고, "현재 기준으로 새로 계산" 버튼을 둡니다.

### 2.8 광고 (Android)

- AdMob 전면 광고는 **"결과 보기"를 누를 때만** 나오고, 한 번 나온 뒤 **5분** 동안은 다시 나오지 않습니다.
- 동의(UMP)를 먼저 받습니다. 광고가 실패해도 결과는 막지 않습니다.

### 3.4 화면 규칙

- **운 흐름은 모두 오른쪽→왼쪽입니다.** 대운·세운·월운 모두 가장 이른 것이 오른쪽 끝에 옵니다.
  - 월운 12개는 6칸씩 두 줄이고, 윗줄은 1~6월, 아랫줄은 7~12월입니다.
  - 상세 이동 화살표도 화면 방향을 따릅니다: `<` 다음 운, `>` 이전 운.
- 원국표는 왼쪽부터 시·일·월·년입니다.
- 자미두수 명반 4×4 지지 배치:
  ```
  사  오  미  신
  진  ·   ·   유
  묘  ·   ·   술
  인  축  자  해
  ```
- 명반 칸 안의 배치(1.02에서 정리, 글자 겹침 없음):
  - 왼쪽 위: 궁 이름 + 주성(세로쓰기)
  - 그 아래: 밝기와 사화 배지
  - 오른쪽 위: 잡성
  - 아래: 궁 간지, 대한 나이, 12신
- 휴대폰 화면 폭(360px)부터 태블릿·PC까지 대응합니다.
  - 태블릿·PC에서는 입력과 결과를 2단으로 배치하고, 궁 상세는 옆에 엽니다.
  - 휴대폰에서는 궁 상세를 오버레이로 띄웁니다.
- 글씨 150% 확대에서도 탭과 표가 잘리지 않아야 합니다.
- 접근성: 명반 칸마다 화면 낭독기용 한 문장 요약이 필요합니다(앱의 `spokenSummary()`).
  - 예: "명궁 정유, 대한 6-15세, 태양 함, 천량 득, 두 번 탭하면 상세 보기"

## 4. 사주팔자 계산 규칙

> 원본 코드: `INSEOL_APP/app/src/main/assets/engine/saju_engine.html`(약 720줄, **이미 JavaScript**) + `lunar.js`(6tail lunar-javascript).
> 입력 준비: `model/SajuModels.kt`(`KoreanTimeRules`), `model/KoreanBirthCalendar.kt`, `engine/CalculationPayload.kt`
> 웹앱에서는 `saju_engine.html`의 계산 함수를 그대로 모듈로 옮기면 됩니다. 결과 JSON 형식도 같게 유지하세요.

### 4.1 입력을 양력 시각으로 바꾸기

1. 음력 입력은 **한국 음력**으로 양력 날짜를 구합니다. 윤달과 음력 2월 30일도 처리합니다.
   - 라이브러리: KoreanLunarCalendar (usingsky, MIT)
2. 시간 보정. 원래 시각에 아래 값을 더합니다.

| 보정 | 값 |
| --- | --- |
| 표준 자오선 | 기본 동경 135도 → **−30분**. 1954-03-21~1961-08-09는 동경 127.5도 → 0분 |
| 서머타임 | 1948~1951, 1955~1960, 1987~1988년 기간 안이면 **−60분** |
| 지역 경도(선택) | 도시 오프셋 + 30분 (예: 서울 −32 → −2분) |

- 서머타임 기간(시작 ~ 끝, 끝은 제외):

  | 연도 | 기간 |
  | --- | --- |
  | 1948 | 6/1 0시 ~ 9/13 0시 |
  | 1949 | 4/3 ~ 9/11 |
  | 1950 | 4/1 ~ 9/10 |
  | 1951 | 5/6 ~ 9/9 |
  | 1955 | 5/5 ~ 9/9 |
  | 1956 | 5/20 ~ 9/30 |
  | 1957 | 5/5 ~ 9/22 |
  | 1958 | 5/4 ~ 9/21 |
  | 1959 | 5/3 ~ 9/20 |
  | 1960 | 5/1 ~ 9/18 |
  | 1987 | 5/10 2시 ~ 10/11 3시 |
  | 1988 | 5/8 2시 ~ 10/9 3시 |

- 시작 직후 1시간(시계를 앞당겨 없는 시각)과 1961-08-10 0:00~0:30은 **입력을 막습니다**.
- 끝나는 시각 직전 1시간(같은 시각이 두 번 있는 경우)은 사용자가 앞/뒤를 고릅니다.
- 원본: `KoreanTimeRules` in `SajuModels.kt`

### 4.2 기둥 정하기

- **시주·일주**: 보정된 시각으로 계산합니다.
  - 보정 시각이 **23시대면 다음 날 0시로 넘겨** 일주를 바꿉니다(자시 일자 전환). `eightChar.setSect(2)`.
  - 시지: 자시 23:00~01:00, 축시 01:00~03:00 … (보정 시각 기준이라 한국 시계로는 자시가 23:30~01:30입니다.)
- **년주·월주** (1.06, 계산 기준 KR-2026.10-4): 절기(입춘·절입) 기준입니다.
  - 절입 비교에는 보정 시각이 아니라 **실제 출생 순간**을 씁니다. 한국 시각에서 서머타임을 빼고 UTC+8로 바꾼 시각입니다(1954~1961년은 UTC+8:30에서 환산). lunar.js의 절기표가 UTC+8 기준이기 때문입니다.
  - 계산식: `절기 비교 시각 = 출생 시각 + 표준자오선 보정 + 서머타임 보정 − 30분`. 지역 경도 보정은 넣지 않습니다.
  - 엔진은 이 시각으로 구한 년·월주가 보정 시각 결과와 다를 때만 년·월주와 대운을 바꿉니다. 절입 직전 약 30분 구간만 해당합니다.
  - 원본: `KoreanBirthCalendar.termClockDateTime`, 엔진의 `termClockEightChar`
- 기둥 순서(데이터·화면 모두): 시 / 일 / 월 / 년.

### 4.3 파생 값

| 항목 | 규칙 |
| --- | --- |
| 지장간 | 엔진 자체 표 `HIDDEN_STEMS` (예: 寅 = 戊丙甲, 辰 = 乙癸戊, 亥 = 戊甲壬) |
| 십신 | 일간과 대상의 오행 차이 + 음양이 같은지 다른지 (`calcTenGod`) |
| 12운성 | 일간 기준 `START_JI` 표. 양간은 순행, 음간은 역행 (`get12Woonseong`) |
| 오행 가중치 | 년간 10, 년지 10, 월간 10, **월지 30**, 일간 10, **일지 20**, 시간 10, 시지 10 |
| 합충 반영 | `useTransformOption=true`이면 합화·충을 반영해 비율을 다시 계산 |
| 합충 | **인접한 기둥끼리만** 천간합(5합), 지지 육합, 지지 육충 |
| 강약 | 점수가 극강 ≥55 / 신강 ≥18 / 중화 >−18 / 신약 >−50 / 그 아래 극약 |
| 용신(억부) | 신강이면 식상·재·관 중 가장 약한 오행, 신약이면 비겁·인성 중 가장 약한 오행. 희신 = 용신을 생하는 오행, 기신 = 용신을 극하는 오행, 구신 = 희신을 극하는 오행 |
| 격국 | 월지 십신으로 결정(비견→건록격, 겁재→양인격, 편관→칠살격 등). 조건이 맞으면 `전왕격 후보` |
| 대운 | lunar.js `getYun(성별, 2)`. 시작 나이 반올림, **8개** |
| 세운 | 엔진이 대운마다 10년치(`daewunYearFortunes`)를 함께 돌려줍니다. 화면은 선택한 대운의 10년 |
| 월운 | 올해 12개월 |

### 4.4 출생시간 모름

- 시주를 만들지 않습니다. 일주는 그 날짜 정오 기준의 참고값입니다.
- 년·월주는 그날 하루의 모든 가능한 시각(30분 간격 + 0:00, 23:59, 서머타임 앞/뒤)을 계산해, **모두 같을 때만** 확정합니다.
- 그날이 절입일이면 `boundaryTerm`을 돌려줍니다.
  - 절입 시각(그날 한국 시계 기준)과, 절입 1시간 전·후의 월(·년)주가 들어 있습니다.
  - 화면에는 "절입 후 | 절입 전"을 한 표로 보여 줍니다.
- 강약·용신·비율·대운·세운·월운은 계산하지 않습니다.

### 4.5 엔진 입출력 (그대로 유지 권장)

- 입력 JSON 주요 값:
  - `year, month, day, hour, minute`: 보정된 시각
  - `isNormalized: true`, `genderCode`(남 1 / 여 0), `useTransformOption`
  - `termClock {year, month, day, hour, minute}`: 절기 비교 시각
  - 출생시간 모름이면 `timeUnknown: true`, `samples[]`(각 시각의 보정 시각과 termClock), `civilMinutesFromTermClock`
- 출력 JSON:
  - `pillars[]`: title, stem{hanja, korean, element}, stemTenGod, branch, branchTenGod, hiddenStems, growthPhase
  - 비율: `elementRatios`, `tenGodRatios`
  - 해석 값: `strengthText`, 용신 4개, `geukgukLabel`, `combinations`
  - 운: `bigFortunes`, `yearFortunes`, `monthFortunes`, `daewunYearFortunes`
  - 출생시간 모름: `incompleteBirthTime`, `uncertainPillars`, `boundaryTerm`

## 5. 자미두수 명반 계산 규칙

> 원본 코드: `INSEOL_APP/app/src/main/java/com/lifedesign/saju/domain/JamidusuCalculator.kt` (Kotlin 약 700줄)
> 웹앱에서는 TypeScript로 옮겨야 합니다. 별 표와 묘왕리함 표를 **글자 하나까지 그대로** 옮기세요.

지지 인덱스: 자0 축1 인2 묘3 진4 사5 오6 미7 신8 유9 술10 해11.

### 5.1 기준 날짜와 시

- 날짜: 입력 양력 날짜의 **한국 음력**입니다. 시간 보정 때문에 날짜를 바꾸지 않습니다.
- 윤달은 같은 번호의 달로 배치합니다(예: 1987-08-12 = 윤6월 18일 → 6월).
- 생년 간지: `음력 연도 − 4`의 60갑자입니다. 입춘이 아니라 **음력 설** 기준입니다.
- 시지: 보정된 시각의 시 `(hour + 1) / 2`(정수 나눗셈)이고, 23시는 자시입니다.

### 5.2 명궁·신궁·오행국

- 월 기준점 = 인(2)에서 음력 월만큼 순행(`2 + 월 − 1`).
- 명궁 = 월 기준점에서 시지 수만큼 **역행**. 신궁 = **순행**.
- 궁간은 오호둔으로 정합니다.

  | 생년 천간 | 인궁 천간 |
  | --- | --- |
  | 갑·기 | 丙寅 |
  | 을·경 | 戊寅 |
  | 병·신 | 庚寅 |
  | 정·임 | 壬寅 |
  | 무·계 | 甲寅 |

- 오행국: 명궁 간지의 납음 → 수2·목3·금4·토5·화6국. **대한 시작 나이 = 국수**.

### 5.3 14주성

- 자미 위치: `음력 일 + 보정값`이 국수로 나누어떨어질 때까지 보정값을 1씩 늘립니다. `(몫 − 1)`에 보정값이 짝수면 더하고 홀수면 뺍니다. 결과는 인궁 기준 위치입니다.
- 자미계(자미에서 역행): 자미 0, 천기 −1, 태양 −3, 무곡 −4, 천동 −5, 염정 −8.
- 천부 위치 = 인궁 기준 `12 − 자미 위치`(인신축 대칭).
- 천부계(천부에서 순행): 천부 0, 태음 +1, 탐랑 +2, 거문 +3, 천상 +4, 천량 +5, 칠살 +6, 파군 +10.

### 5.4 보좌·살성

| 별 | 기준 |
| --- | --- |
| 좌보 / 우필 | 진에서 생월 순행 / 술에서 생월 역행 |
| 문창 / 문곡 | 술에서 생시 역행 / 진에서 생시 순행 |
| 지공 / 지겁 | 해에서 생시 역행 / 해에서 생시 순행 |
| 천괴·천월·녹존 | 생년 천간 표 |
| 경양 / 타라 | 녹존 +1 / 녹존 −1 |
| 천마 | 생년 지지 삼합 (인오술→신, 사유축→해, 신자진→인, 해묘미→사) |
| 화성·영성 | 생년 지지 삼합 기준점 + 생시 |

잡성 약 30개는 생년·생월·생일·생시·명궁/신궁 기준 표로 배치합니다. 표는 원본 코드에서 그대로 옮기세요.
- 대상: 천형·천요·음살·천무·천공·순공·절공·삼태·팔좌·은광·천귀·태보·봉고·홍란·천희·화개·함지·고진·과숙·천재·천수·천주·파쇄·비렴·용지·봉각·천곡·천허·천관·천복·천덕·월덕·해신·천상·천사

| 천간 | 록 | 권 | 과 | 기 |
| --- | --- | --- | --- | --- |
| 갑 | 염정 | 파군 | 무곡 | 태양 |

### 5.6 12궁·대한·12신·밝기

- 12궁 이름은 명궁에서 **역행**합니다: 명·형제·부처·자녀·재백·질액·천이·노복·관록·전택·복덕·부모.
- 대한 방향: 양남·음녀는 순행, 음남·양녀는 역행. 각 궁의 대한 = 국수 + 10 × 거리.
- 칸 아래 4줄:
  - 장생 12운: 국수별 표, 대한 방향
  - 박사 12신: 녹존부터, 대한 방향
  - 태세 12신: 연지부터 순행
  - 장성 12신: 삼합 왕지부터 순행
- 묘왕리함은 주성표와 보좌·살성표(문창·문곡·화성·영성·경양·타라)를 지지별로 찾습니다. 출처 표기는 "앱 기준 묘왕리함표"입니다.

### 5.7 대한·유년 명반

- 대한: 선천 궁 가운데 대한 시작 나이가 선택한 나이에 가장 가까운 궁이 대한 명궁입니다. 그 궁의 천간으로 대한 사화(대록·대권…)를 붙이고 12궁 이름만 다시 돕니다. **별 위치는 바뀌지 않습니다.**
- 유년: 해당 연도 지지의 궁이 유년 명궁이고, 연간으로 유년 사화(년록…)를 붙입니다.

## 8. 웹앱 기술 방향 (권장)

### 8.1 구조

```
브라우저 (PWA, 오프라인 가능)
 ├─ 입력 → 한국 음력 변환 + 시간 보정 (KoreanBirthCalendar 이식)
 ├─ 사주 엔진 (saju_engine.html의 JS + lunar.js 그대로)
 ├─ 자미두수 엔진 (JamidusuCalculator.kt → TypeScript)
 ├─ 통변 (Tongbyeon.kt, JamidusuInterpretation.kt → TypeScript)
 └─ 보관함 = 브라우저 localStorage / IndexedDB (서버 저장 없음)
```

- **서버 없이 정적 사이트**로 만듭니다. 출생 정보가 서버로 가지 않아 개인정보 부담이 적고, 호스팅비가 거의 없습니다.
- 기술 예시: Vite + TypeScript + (React 또는 Svelte), PWA 플러그인.
- 호스팅: Cloudflare Pages, Netlify, Vercel, GitHub Pages(모두 무료 등급 있음).
- **자체 도메인**을 권장합니다(예: inseol.kr, inseolmyeongri.com).
  - AdSense 승인과 `ads.txt` 게시에는 사이트 최상위 도메인 관리 권한이 필요합니다. `github.io` 같은 공용 하위 도메인으로는 진행이 어렵습니다.

## 9. 수익화 계획

### 9.1 광고 (Google AdSense)

- 웹은 AdMob이 아니라 **AdSense**를 씁니다. 같은 Google 계정으로 가입할 수 있고, 게시자 ID(pub-…)도 AdMob과 같을 수 있습니다.
- 승인 조건(요약):
  - 자체 도메인, 충분한 고유 콘텐츠(8.3의 정적 글 페이지가 도움이 됨)
  - 개인정보처리방침과 문의처
  - 사이트 루트에 `ads.txt`
  - 신청 전에 AdSense 최신 정책을 다시 확인하세요.
- 배치 권장(앱의 원칙 유지: **결과를 막지 않는다**):
  - 결과 화면의 카드 사이에 디스플레이 광고 1~2개(예: 원국 아래, 통변 아래)
  - 정적 글 페이지의 본문 중간과 끝
  - 입력 칸·명반 칸 사이나 탭 바로 옆에는 넣지 않습니다(실수 클릭 유도 금지).
  - 전면형(비네트) 광고는 AdSense 자동 광고 설정으로 켤 수 있습니다. 앱처럼 "결과 보기"에만 강제로 띄우는 방식은 웹 정책상 어렵습니다.
- 개인정보 동의: EEA·영국 방문자에게는 Google 인증 동의 관리 플랫폼(CMP)이 필요합니다. AdSense의 "개인정보 보호 및 메시지" 기능으로 설정할 수 있습니다.

### 9.2 유입 늘리기

- 검색(SEO)
  - 페이지 제목과 설명에 "만세력", "사주 만세력", "자미두수 명반", "무료 사주", "오늘의 일진" 같은 핵심어를 넣습니다.
  - 공개 글 페이지를 꾸준히 추가하고, 사이트맵을 제출합니다(Google Search Console, 네이버 서치어드바이저).
- 네이버 노출: 한국 사용자는 네이버 비중이 크므로 **네이버 서치어드바이저** 등록이 필수입니다.
- 앱과의 연결: 웹 → 앱 설치 안내, 앱 → 웹 글 링크.

### 9.3 이후 선택할 수 있는 유료 기능 (나중에)

- 광고 없는 버전, 자세한 PDF 리포트(사주+자미두수 종합 통변 확장), 궁합 등
