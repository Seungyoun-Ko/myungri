# 예전 만세력 페이지 (보관용)

인설명리 웹앱(`web/`)을 만들기 전에 쓰던 페이지들입니다. 지금 사이트(app.inseol.com)에는 올라가지 않고, 참고용으로만 남겨 둡니다.

- 계산 기준이 Android 앱과 다릅니다. 절입을 날짜로만 비교하고, 서머타임 기간과 보정 방식도 다릅니다.
- `pillar-weighting.md`의 기둥별 가중치(년 10 · 월 20 · 일 50 · 시 20)는 앱 기준(월지 30 · 일지 20 · 나머지 10)과 다릅니다.
- `index.html`에 있는 우클릭 막기·개발자도구 감지 코드는 실제 보호 효과가 없어 새 웹앱에는 넣지 않았습니다.
